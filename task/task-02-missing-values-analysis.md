## 🏢 02. Business Scenario — Why Does This Matter?

Imagine you are working as a Junior Data Analyst at a retail company.

The company has provided a sales transaction dataset covering 2022–2025.

Before the dataset can be used for reliable reporting and further analysis, management wants to understand whether any information is missing.

Missing values can affect calculations, customer analysis, sales summaries, and other business metrics. However, not every missing value necessarily represents an error.

Some values may be unavailable, not applicable, or absent because of normal business processes.

Your responsibility is to investigate the missing data, measure its extent, and report your findings.

### 🎯 Questions from Management

Your manager wants answers to the following questions:

1. Which columns contain missing values?
2. How many missing values are present in each column?
3. What percentage of each column is missing?
4. How many missing cells exist across the entire dataset?
5. Which column contains the highest number of missing values?
6. Could these missing values affect future business analysis?
7. What additional investigation might be necessary to understand why the values are missing?

**Your mission is to provide evidence-based answers to these questions.**

> [!IMPORTANT]
> **Do not fill in missing values or delete any rows during this task.**
>
> Your responsibility is to identify, measure, investigate, and document the missing data before recommending any corrective action.

## 📋 04. Your Tasks

This assignment contains six subtasks.

### Task 2.1 — Missing Values Count

**Objective:** Determine how many values are missing in each column.

**Your responsibilities:**

- Calculate the missing value count for every column.
- Identify columns with one or more missing values.
- Present the results in a readable format.

**Expected output:** A column-wise missing value count summary.

### Task 2.2 — Missing Values Percentage

**Objective:** Determine what percentage of each column's values is missing.

**Your responsibilities:**

- Calculate the percentage of missing values for every column.
- Compare missing value percentages across columns.
- Identify columns where missingness may warrant further investigation.

**Expected output:** A table containing missing value counts and percentages.

### Task 2.3 — Columns with Missing Values

**Objective:** Identify which columns contain missing information.

**Your responsibilities:**

- List all columns containing missing values.
- Separate columns with missing values from columns without missing values.
- Report how many columns contain missing values.

**Expected output:** A clear list of affected columns and a summary of their count.

### Task 2.4 — Total Missing Values

**Objective:** Calculate the total number of missing cells in the entire dataset.

**Your responsibilities:**

- Calculate the total number of missing values across all columns.
- Document the result.
- Explain what this number represents.

**Expected output:** The total number of missing cells in the dataset.

### Task 2.5 — Column with the Highest Missing Values

**Objective:** Determine which column contains the highest number of missing values.

**Your responsibilities:**

- Compare missing value counts across columns.
- Identify the column with the highest count.
- Record its missing value count and percentage.
- Consider whether the column's business meaning makes the missingness important.

**Expected output:** The column with the highest missing value count, supported by numerical evidence.

**Note:** If multiple columns share the highest count, report all tied columns.

### Task 2.6 — Business Interpretation

**Objective:** Explain the potential business implications of the findings.

Answer the following questions based on your results:

1. Which columns contain missing values?
2. Which column has the highest number of missing values?
3. How many missing cells exist in total?
4. Which missing values could affect future analysis?
5. What additional information would help explain why the values are missing?
6. What should be investigated before deciding whether to fill in or otherwise handle the missing values?

**Expected output:** A concise business interpretation supported by your analysis.

> **Important:** You can identify missing values using the dataset, but you cannot determine their actual cause from missingness alone. Further investigation may be required.
